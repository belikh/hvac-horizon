# Feature matrix against the four competitors

Sources: VT = Versatile Thermostat, RM = RoomMind, CA = ClimateAdvisor, PID = smart_thermostat (ScratMan), ours = this integration's own feature, with no competitor.

Checked against commit 43f37b9. Code paths are under `custom_components/hvac_horizon/` unless a cell names `tests/`. HA tests are in `tests/ha/test_setup.py`. Unit tests are in `tests/test_*.py`. A test named `Class.method` sits in that class. Line numbers are for `coordinator.py` unless a cell names another file.

Status values:
- `drives`: a call writes a device or setpoint, or a value the control path reads changes that write. A row is drives only when a test with the real decide() (not a stub) shows a write that differs from the write without the feature. The cell cites the call site, the gates and the test. A test that asserts the write through the coordinator (`tests/ha/test_setup.py`) counts the same way.
- `published`: a sensor or attribute shows the value, and no control path reads it. The cell cites the sensor.py line.
- `control`: a gate, service, repair issue, notification, event, view or user action without a setpoint write. The cell cites the call site and the test. `Test: none` means no test covers it.
- `pure`: must be zero.
- `missing`: not built. The cell gives the reason in one line.

This file reflects the code on `main` at the time of the last update. Update it when a row changes.
