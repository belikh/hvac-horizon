# Feature matrix against the four competitors

Sources: VT = Versatile Thermostat, RM = RoomMind, CA = ClimateAdvisor, PID = smart_thermostat (ScratMan), ours = this integration's own feature, with no competitor.

Checked against commit 1fc2bab (rows edited by hand after 7b08d41: inhibition, MPC heat, natural ventilation). Code paths are under `custom_components/hvac_horizon/` unless a cell names `tests/`. HA tests are in `tests/ha/test_setup.py`. Unit tests are in `tests/test_*.py`. A test named `Class.method` sits in that class. Line numbers are for `coordinator.py` unless a cell names another file.

Status values:
- `drives`: a call writes a device or setpoint, or a value the control path reads changes that write. Proof: a test that runs the real decide() (no stub of decide) and shows a device write that differs from the write without the feature. The cell cites the call site, the gates and the test.
- `published`: a sensor or status attribute shows the value, and no control path reads it.
- `control`: a gate, service, repair issue, notification, event, view or user action that does not write a setpoint or device.
- `pure`: must be zero.
- `missing`: not built. The cell gives the reason in one line.

A `drives` cell that cites no test asserting the write says so. A cell marked `function test only` cites only a unit test in `tests/test_*.py`.

This file reflects the code on `main` at the time of the last update. Update it when a row changes.
